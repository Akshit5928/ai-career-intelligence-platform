# Data Cleaning & EDA Portfolio Project

## Objective
Demonstrate an internship-ready workflow for turning a messy tabular dataset into reliable analytical insights.

## Workflow
1. Inspect schema and data quality
2. Handle missing values and duplicates
3. Validate types and ranges
4. Detect and document outliers
5. Perform exploratory data analysis
6. Create business-facing visualizations
7. Summarize actionable findings

## Skills demonstrated
- Python
- Pandas / NumPy
- Data cleaning
- Exploratory data analysis
- Statistics
- Visualization
- Reproducible documentation

## Planned deliverables
- `notebooks/eda.ipynb`
- `src/cleaning.py`
- `tests/`
- cleaned dataset or reproducible data-loading instructions
- final findings and limitations

> Dataset selection and numerical findings will be added only after the source data is actually ingested and analyzed; no results are fabricated.
