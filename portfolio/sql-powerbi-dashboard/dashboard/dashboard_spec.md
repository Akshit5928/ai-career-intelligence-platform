# Dashboard specification

## KPI cards
- Total revenue
- Total orders
- Average order value

## Visuals
- Monthly revenue trend
- Revenue by country
- Top 10 customers
- Monthly order volume
- Top 10 products

## Filters
- Date range
- Country
- Customer
- Product / StockCode

## Data model
The dashboard is built from the cleaned UCI Online Retail transaction table. Revenue is derived as `quantity * unit_price`.

## Insight standard
Every insight must be derived from verified query output. Do not publish invented values or conclusions.
