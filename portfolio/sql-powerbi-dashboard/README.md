# SQL + Power BI Internship Dashboard

## Goal
A portfolio-ready analytics project demonstrating SQL, data cleaning, KPI design, and Power BI-style business reporting.

## Deliverables
- Cleaned analytics dataset
- 5–7 SQL queries covering core business questions
- Dashboard specification for Power BI
- Three evidence-based business insights
- Automated tests for SQL/query assumptions

## Current status
Scaffolded on branch `feat/sql-powerbi-dashboard`. No business findings are claimed until a real dataset is added and analyzed.

## Planned workflow
1. Add a public dataset and record its source.
2. Validate schema, nulls, duplicates, and data types.
3. Load data into PostgreSQL/Supabase for SQL analysis.
4. Implement KPI and segmentation queries.
5. Build the Power BI dashboard from verified query outputs.
6. Document findings, limitations, and reproducible steps.

## Internship relevance
Targets recurring entry-level requirements around SQL, data cleaning, dashboarding, business insights, documentation, and reproducible analysis.
