# Frontend Command Center

The dashboard is organized around the career-agent workflow:

- Overview: current readiness, top matches, skill priorities and agent health.
- Opportunities: ranked internship feed with deadline, source and missing-skill context.
- Skill Intelligence: market demand versus user readiness.
- Portfolio: 120-day major/minor project progress with the active project highlighted.
- Applications: approval-gated pipeline; no automatic submission.
- GitHub: repository health and public-action status.
- LinkedIn: genuine-work drafts and approval status.
- Research Agent: auditable research cycles and source runs.

All public actions remain approval-gated. The frontend must never imply an application, post, merge, or notification happened unless the API reports it as completed.
